# SWVL CAD Files

This directory contains all of the CAD files for the SWVL gimbal, which will be 3D-printed to form the final gimbal structure.

## Endstop Pins
- Quantity: 4
- Supports: No
- Infill: 100%
- Layer Height: 0.1mm-0.2mm

## Pan Axis
- Quantity: 1
- Supports: Yes
- Infill: 20%
- Layer Height: 0.1mm-0.2mm

## Everything Else
- Quantity: 1
- Supports: No
- Infill: 20%
- Layer Height: 0.1mm-0.2mm

## Other Parts
One of [these bearings](https://www.amazon.com/dp/B082PRVZ7B) should be inserted into the hole in the bearing riser, and four of [these screws](https://www.amazon.com/dp/B01B1OD4Y2) should be used to secure the motor to the motor riser.
